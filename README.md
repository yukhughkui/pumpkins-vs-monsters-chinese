# 南瓜大战僵尸 · 中文汉化版 v16.0

> 原游戏为《Pumpkins vs Monsters》（南瓜大战怪物），著作权归原作者与发行方所有。
> 本仓库是**非官方的个人汉化补丁包**，仅用于技术交流与学习，未改动任何游戏逻辑，也未解锁任何付费内容。

## 这是什么

一款只有英文版的手游，被改成了中文。

难点在于：它**没有 `strings.xml`，没有 `values-zh`，没有任何可以替换的字符串**——全部的界面文字都画在 1017 张 `.PGT` 贴图里，连暂停菜单上的「继续」都是一张像素图。

所以这件事不是「翻译」，而是「重画」。

做法：破解 `.PGT` 封装格式 → 取出内嵌 PNG → 逐张抹掉英文并重新绘制中文 → 按原字节结构塞回 APK → 修包名、修启动类名、删多余权限 → 重新签名出包。
**整个过程没有改动一行游戏代码。**

## 安装

1. 从右侧 **Releases → v1.0** 下载附件 `PumpkinsVsMonsters-CN-v16.0.apk`，或直接取仓库根目录的 `南瓜大战僵尸_中文版_16.0.apk`，传到手机。
   （GitHub 的 Release 附件不支持中文文件名，会把汉字替换成占位符，所以附件用了英文名；两份文件内容完全相同，SHA-256 都是上表那个值。）
2. 安装时按提示允许「未知来源应用」。
3. **不需要卸载原版英文版**。包名已改为 `_CN` 结尾，两个版本可以同时存在，互不覆盖，存档也相互独立。
4. 已装过旧版汉化包的话，直接覆盖安装即可，进度不会丢（存档在应用私有目录里）。

## 汉化范围

98 张贴图，覆盖到能触发的全部界面文本：

- 主菜单、故事模式入口
- 六个关卡名：木乃伊归来 / 领土保卫战 / 玛雅之战 / 明日城堡 / 水晶帝国 / 万圣夜
- 暂停菜单：继续 / 菜单 / 帮助 / 波次
- 帮助说明与多行战斗提示
- 关卡解锁条件提示
- 三类结算面板：关卡通过 / 关卡失败 / 游戏结束
- 商店、道具购买弹窗、老虎机
- 战斗中的连击与波次提示

字体统一换成思源黑体 Bold，采用 4 倍超采样渲染再降采样，并对每张图做二分搜索定最大字号——所以关卡名之间的字号是一致的，小字也不会糊。

## 相对官方 16.0 版做了什么

| # | 改动 | 原因 |
|---|---|---|
| 1 | 重封 98 张 `.PGT` 贴图 | 中文字形替换，PNG 数据段整体重写，厂商私有头与尾部填充按原字节保留 |
| 2 | 包名 `_AD` → `_CN` | 与原签名不同的包无法覆盖原版，改为共存安装 |
| 3 | 启动 Activity 改为绝对类名 | 原 Manifest 写的是相对类名 `.main`，改包名后会拼错导致 `ClassNotFoundException` 闪退 |
| 4 | 桌面应用名改为「南瓜大战僵尸」 | 写死在 `resources.arsc` 里 |
| 5 | 删除 `WRITE_EXTERNAL_STORAGE` | 原版仅广告 SDK 使用，存档走私有目录，非必要权限 |
| 6 | v1 + v2 重签名 | 自签名，API 16 / 20 / 25 / 30 / 34 全部校验通过 |

其余 1067 个条目（代码、音频、原始素材、资源表）与官方包逐字节一致。

## 已知状况

- 原包未声明 `targetSdk`（`minSdk`=4），部分国产系统会在首次启动时提示「是否全屏显示」。这是系统对老应用的自动行为，不是权限申请，应用侧无法关闭，可在系统「应用设置 → 全屏显示」里手动处理。
- 内购相关文案已汉化，但付费流程未在真机实测（原版依赖 Google Play 服务）。
- 音频、图集原始数据未做任何改动。
