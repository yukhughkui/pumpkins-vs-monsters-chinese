## 安装

1. 下载上面任一版本，传到手机。
2. 安装时按提示允许「未知来源应用」。
3. **不需要卸载原版英文版**。包名已改为 `_CN` 结尾，可与原版共存，互不覆盖，存档相互独立。
4. 两个版本同包名、同签名，可**直接互相覆盖安装**，进度不会丢（存档在应用私有目录里）；但爽玩版启动时会把资源刷满，覆盖后存档数值会被重写。

## 这是什么

一款只有英文版的手游，被改成了中文。

难点在于：它**没有 `strings.xml`，没有 `values-zh`，没有任何可以替换的字符串**——全部的界面文字都画在 1017 张 `.PGT` 贴图里，连暂停菜单上的「继续」都是一张像素图。

所以这件事不是「翻译」，而是「重画」。

做法：破解 `.PGT` 封装格式 → 取出内嵌 PNG → 逐张抹掉英文并重新绘制中文 → 按原字节结构塞回 APK → 修包名、修启动类名、删多余权限 → 重新签名出包。
**中文汉化版整个过程没有改动一行游戏代码；只有爽玩版动了 `classes.dex`。**

- 暂停菜单：继续 / 菜单 / 帮助 / 波次

- 关卡解锁条件提示

字体统一换成思源黑体 Bold，采用 4 倍超采样渲染再降采样，并对每张图做二分搜索定最大字号——所以关卡名之间的字号是一致的，小字也不会糊。

## 爽玩版额外改了什么

在中文汉化版基础上，只替换 `classes.dex` 与一张「-1」价格贴图，其余 1000 多个条目逐字节不变。共 9 组补丁：

| # | 改动 | 效果 |
|---|---|---|
| 1 | 价格函数恒返回 -1 | 购买判定恒成立，扣款变成「买一件倒赚 1 金币」 |
| 2 | 数字绘制器加 -1 特判 | 原绘制器用 `Math.abs` 会吃掉负号，改用专用贴图显示 `-1` |
| 3 | 关卡解锁判定恒 true | 不需要打关解锁 |
| 4 | 商店道具解锁判定恒 true | 开局即可用全部道具 |
| 5 | 启动时刷满资源 | 金币 99999 / 宝石 999 / 12 种道具 99 / 永久去广告，老存档也生效 |
| 6 | 道具上限 25 → 99 | 并绕过「库存已满」拦截，否则满仓反而买不了 |
| 7 | 通关奖励 ×10 | 金币 +10→+100、+20→+200，宝石 +1→+10 |
| 8 | 老虎机固定最高档 | +5000 金币、三种道具与宝石各 +9 |
| 9 | 伤害计算函数返回值 ×2 | 所有武器与升级等级一视同仁；敌人初始血量、关卡数据、坐标均未改动 |

爽玩版保留关卡节奏，不是一刀秒杀的割草版。

## 相对官方 16.0 版做了什么（两个版本共有的汉化改动）

| # | 改动 | 原因 |
|---|---|---|
| 1 | 重封 98 张 `.PGT` 贴图 | 中文字形替换，PNG 数据段整体重写，厂商私有头与尾部填充按原字节保留 |
| 2 | 包名 `_AD` → `_CN` | 与原签名不同的包无法覆盖原版，改为共存安装 |
| 3 | 启动 Activity 改为绝对类名 | 原 Manifest 写的是相对类名 `.main`，改包名后会拼错导致 `ClassNotFoundException` 闪退 |
| 4 | 桌面应用名改为「南瓜大战僵尸」 | 写死在 `resources.arsc` 里 |
| 5 | 删除 `WRITE_EXTERNAL_STORAGE` | 原版仅广告 SDK 使用，存档走私有目录，非必要权限 |
| 6 | v1 + v2 重签名 | 自签名，API 16 / 20 / 25 / 30 / 34 全部校验通过 |

除上述改动外，代码、音频、原始素材等条目与官方包逐字节一致。

## 已知状况

- 原包未声明 `targetSdk`（`minSdk`=4），部分国产系统会在首次启动时提示「是否全屏显示」。这是系统对老应用的自动行为，不是权限申请，应用侧无法关闭，可在系统「应用设置 → 全屏显示」里手动处理。
- 内购相关文案已汉化，但付费流程未在真机实测（原版依赖 Google Play 服务）。
- **爽玩版只做了静态验证（补丁特征、签名、资源完整性逐项核对），未在真机实跑**，建议先打一关确认商店与结算表现。
- 音频、图集原始数据未做任何改动。
